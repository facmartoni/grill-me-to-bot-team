# grill-me-to-bot-team

Grill a **bot team** design (utility contracts, problem + system-boundary naming), then stand up the squad only after shared understanding.

Companion to Matt Pocock's [grill-me](https://github.com/mattpocock/skills/tree/main/skills/grill-me) / grilling interview style.

## Install

```bash
npx skills add https://github.com/facmartoni/grill-me-to-bot-team --skill grill-me-to-bot-team -y -g
```

Also install grill companions if you do not have them:

```bash
npx skills add https://github.com/mattpocock/skills --skill grill-me -y -g
npx skills add https://github.com/mattpocock/skills --skill grilling -y -g
```

## Use

Ask your agent to run `/grill-me-to-bot-team` or "grill me into a bot team" for a domain under a lead (CTO, CPO, …). One question per round by default; create agents only when you confirm shared understanding.
